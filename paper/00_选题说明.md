# 选题建议：皮肤镜病变「分割 → 分割引导分类」两部分递进课题

> 适用条件：单卡 16GB（4060Ti / 4070Ti 量级）、医学影像方向、**目标为硕士毕业（不强求 SCI）**、需要成熟开源 baseline、毕业大论文需两部分工作。
> 本文档配套 `paper/` 目录下已下载的 116 篇论文，目录导读见第 9 节。
> 主推方向已从"息肉分割"切换为"皮肤镜病变分割+分类"，切换理由见第 1 节。原息肉方案完整保留在第 8 节与 `paper/04_*`–`06_*` 目录，随时可回退。

## 0. 结论（先看这段）

**主推课题：面向皮肤镜图像的病变分析方法研究 —— 第一部分做"病灶在哪、边界准不准"，第二部分做"病灶是什么、怎么把稀有类认出来"。**

| | 第一部分 | 第二部分 |
|---|---|---|
| 题目方向 | 边界不确定性感知与频域子带解耦的皮肤镜病变分割网络 | 分割不确定性引导的双分支皮肤病变分类与稀有类识别 |
| 任务 | 语义分割（二值 mask） | 七分类（MEL/NV/BCC/AK/BKL/DF/VASC） |
| 数据 | ISIC 2018 Task1（2594/100/1000）+ ISIC2017 + PH2 | **ISIC 2017（真配对，3 类）** + HAM10000 / ISIC 2018 Task3（10015 张，7 类） |
| 解决的问题 | 病灶-皮肤对比度低、毛发/气泡/标尺伪影、标注者边界分歧 | 类别极度不平衡（稀有类仅占 1%）、总体精度饱和、黑箱不可解释 |
| 关系 | 产出分割网络 + mask + **边界不确定图 U(x)** + **形态学量** | **直接以第一部分的输出为输入**，三个接口全部复用 |
| 主战场指标 | DSC / IoU / SE / SP / HD95 | Balanced Acc / **Macro-F1** / **逐类 F1** / **MEL 召回率** |
| 单次实验反馈 | **1–2 小时** | **30–60 分钟** |

**为什么是它**：在"只求毕业、要求时间少见效快"这个前提下，决定体验的不是新颖度，而是**迭代延迟**和**是否存在拿不到正结果的风险**。这个方向两点都占优：训练图只有 2594 张、输入 256²，一个 U-Net 跑满 200 epoch 约 1.2 小时；分类部分用 timm 的 backbone 跑 50 epoch 约 40 分钟。一个想法错了，代价是一个下午而不是两天。而且两个任务都有**确定性产出**——不存在"做了三个月发现是负结果"的情形，而这恰恰是原主推方案（域泛化）最大的风险。

**代价**：HAM10000 上强 backbone 的总体 accuracy 已经到 ~90%+，靠总精度涨点很难。**对策是换报告口径**——按类别拆开看，DF（115 张）和 VASC（142 张）各占约 1%，它们的 per-class F1 通常只有 60–75%，还有 3–8 个点的真实空间。详见 §1.3 和 §4.4。

## 1. 为什么是它：约束 → 筛选逻辑

### 1.1 三个候选方案的速度对比

| 方案 | 单次实验反馈 | 数据获取 | 总 GPU·h | 主要风险 | 结论 |
|---|---|---|---|---|---|
| **A 皮肤病变 分割→分类** | **分割 1–2h / 分类 30–60min** | ISIC Archive 可直连，无需网盘提取码 | **~49** | 分类总精度饱和（可用报告口径规避） | **主推** |
| B 息肉 精度→轻量化 | 分割 2.5–3h | 百度网盘（提取码 x3jc） | ~70–90 | 两部分偏并列，叙事需重组 | 备选 C |
| C 息肉 精度→泛化 | 泛化每配置 6–8h（训练+5 库评测） | 同上 | ~120–130 | **DG/TTA 对随机种子敏感，容易做出负结果** | 备选 B |

原主推方案被降级只有一个原因：它的第二部分（域泛化 + 测试时自适应）是三个方案里**唯一可能让你花了三个月却拿不到正结果**的环节。风格增强强度调不好就是负迁移；在线 TTA 在医学分割上"越适配越差"是已被文献记录的常见失败模式。在"必须发 SCI"的前提下这个风险值得冒（泛化提升空间大、故事好卖）；在"只求毕业"的前提下不值得——毕业要的是**确定能写完的实验矩阵**，不是高风险高回报。

### 1.2 拥挤度实测（arXiv API 精确计数，2026-10-01）

| 关键词 | 2023 | 2024 | 2025.01–2026.09 |
|---|---|---|---|
| polyp segmentation | 50 | 55 | **74** |
| skin lesion segmentation | 30 | 12 | 28 |
| skin lesion classification | 20 | 13 | 41 |
| **skin lesion multi-task** | **1** | **1** | **5** |
| dermoscopic segmentation | 6 | 6 | 24 |

**倒数第二行是这次切换最重要的证据**：把分割和分类联合起来做的工作，21 个月里 arXiv 上只有 5 篇，而息肉分割是 74 篇。你要做的正好落在那个只有 5 篇的位置。

> ⚠️ 必须诚实说明这个统计的偏差：CV 社区习惯先挂 arXiv 再投会议，而皮肤镜方向的很多工作直接投 BSPC / Diagnostics / BMC Medical Imaging 等期刊、不挂预印本。所以皮肤镜的真实论文数被低估，我估计低估 2–3 倍。但即使乘以 3，multi-task 也只有 15 篇左右，仍远低于息肉分割的 74 篇。**相对结论成立，绝对数字别当准。**

### 1.3 "精度饱和"到底是不是致命问题

不是，前提是你换报告口径。HAM10000 的类别分布：

| 类别 | 缩写 | 样本数 | 占比 |
|---|---|---|---|
| 黑色素细胞痣 | NV | 6705 | 66.9% |
| 黑色素瘤 | MEL | 1113 | 11.1% |
| 良性脂溢性角化 | BKL | 1099 | 11.0% |
| 基底细胞癌 | BCC | 514 | 5.1% |
| 光化性角化 | AK | 327 | 3.3% |
| 血管性病变 | VASC | 142 | **1.4%** |
| 皮肤纤维瘤 | DF | 115 | **1.1%** |

一个"全部预测成 NV"的平凡分类器 accuracy 就有 66.9%。所以 accuracy 这个指标在本数据集上本身就是失真的——**你完全有理由不以它为主指标**。改成 Balanced Accuracy / Macro-F1 / 逐类 F1 之后：

- VASC 和 DF 的 per-class F1 在多数已发表工作里只有 60–75%，**这里有 3–8 个点的真实空间**，而且提升手段成熟可靠（class-balanced loss、LDAM、平衡采样、对比学习），不靠运气。
- MEL 的召回率是临床最关心的指标（漏诊黑色素瘤后果最严重），单独报告它有天然的叙事正当性。
- 逐类 F1 有 7 列，加上 balanced acc / macro-F1 / AUC / MEL recall，**表格本身就很饱满**，视觉上完全不像"只涨了 0.5%"。

所以第二部分的论文口径应该是：**"在总体精度已饱和的前提下，改善稀有类识别与临床可解释性"**，而不是"提高分类精度"。这个 framing 一旦定下来，饱和就从劣势变成了你论证问题存在性的依据。

## 2. 方案总览与接口设计

```
        ┌────────────────────────────────────────────────────────┐
        │ 第一部分：边界不确定性感知 + 频域子带解耦 的分割网络      │
        │ (创新点 1/2/3)   数据：ISIC2018 Task1                   │
        │                                                          │
        │ 产出三个接口 ★                                            │
        │   ① 分割网络权重（冻结后给无标注图生成 mask）              │
        │   ② 边界不确定图 U(x)                                     │
        │   ③ 形态学量（不对称性 / 边界不规则度 / 颜色数 / 结构）    │
        └───────────────────────┬────────────────────────────────┘
                                │ 用①给 HAM10000 的 10015 张无标注图
                                │ 自动生成伪 mask（纯推理，约 10 分钟）
                                │ （ISIC2017 侧则直接用官方真 mask）
                                ▼
        ┌────────────────────────────────────────────────────────┐
        │ 第二部分：分割引导的双分支分类                            │
        │ (创新点 1/2/3)   数据：HAM10000 / ISIC2018 Task3         │
        │                                                          │
        │   全图分支 ──┐                                            │
        │              ├─ U(x) 置信度动态门控融合 ──→ 7 类          │
        │   ROI 分支 ──┘        ↑                                   │
        │   (自动 mask 抠图)    └── 形态学量③ 作为 ABCD 先验注入    │
        └────────────────────────────────────────────────────────┘
```

**这个接口设计是让两部分"真递进"而不是"两篇不相关的论文拼在一起"的关键。** 答辩时如果评委问"你这两部分是什么关系"，标准答案是一句话：

> 第一部分的输出不只是 mask，还有 mask 的**可靠性**（边界不确定图）和 mask 的**临床含义**（ABCD 形态学量）；第二部分把这两样都用作显式输入——不确定度决定两个分支的融合权重，形态学量作为可解释先验注入分类器。

三个接口都不是"为了递进而设计"的装饰：mask 本身第二部分必须用（无标注数据要靠它抠 ROI）；U(x) 是 mask 质量的天然度量（自动生成的 mask 一定有对有错，不门控就会被错误 mask 带偏）；形态学量是皮肤科 ABCD 规则的教科书内容（有临床依据，不是拍脑袋造的特征）。

## 3. 第一部分详细设计：皮肤镜病变分割

### 3.1 数据与协议

| 数据集 | 规模 | 用途 |
|---|---|---|
| **ISIC 2018 Task1** | **2594 训练 / 100 验证 / 1000 测试** | **主 benchmark**，几乎所有同类论文都报它 |
| ISIC 2017 Task1 | 2000 / 150 / 600 | 跨数据集泛化测试。**同时是第二部分真配对实验的数据来源**（Task1 与 Task3 是同一批图像，见 §4.1） |
| PH2 | 200（80 普通痣 / 80 非典型痣 / 40 黑色素瘤） | 跨数据集泛化测试（样本极少，只作补充，不作主结果）。⚠️ **只在 Dropbox 分发、无国内镜像，实测超时**，D1–D2 拿不到就直接从计划里删掉 |

- 输入 **256×256**（MALUNet / EGE-UNet / UCM-Net 等轻量工作的社区标准）。Transformer 类主干如需 224²，在表格里注明，**不要偷偷改分辨率**——分辨率变了 DSC 能差 1–2 个点。
- AdamW（`1711.05101`），lr 1e-3，cosine 衰减（`1608.03983`），200 epoch，batch 8–16（按显存调），固定随机种子。
- 增强：随机翻转/旋转、颜色抖动、弹性形变。**注意皮肤镜特有的伪影**：毛发、气泡、暗角、标尺。不要做过度颜色增强——病灶颜色本身就是诊断线索（ABCD 里的 C）。
- ISIC2018 Task1 的 test 集 GT 现已公开，直接用官方三划分，不要自己重切。
- **⚠️ 官方验证集只有 100 张**（不是 1000，这个数字很容易记错）。100 张做 early stopping 的噪声很大——一个样本的 DSC 波动就能影响 1% 的均值。**建议：从 2594 张训练集里再固定切出 10%（约 259 张）作为自己的验证集用于选 epoch，官方那 100 张只在最终报告时跑一次**，并在论文里写清楚这个做法。主结果报 test 1000 张。

### 3.2 三个创新点（每个都可独立消融）

**创新点 1：边界不确定性门控的跳跃连接（Boundary-Uncertainty Gated Skip）**

- 做法：解码器每一级并联一个极轻量分支（3×3 conv → sigmoid）输出边界概率图 `B_l`；用 GT mask 的 `dilation − erosion` 得到边缘带作为监督；跳跃连接特征不再直接相加/拼接，而是经不确定度 `U_l = 1 − B_l` 门控后加权融合。
- **与已有工作的区别（必须写清楚）**：
  - BA-Transformer（`2110.03864`）把边界作为**辅助监督分支**，边界信息不回灌主干；
  - XBound-Former（`2206.00806`）做跨尺度边界建模，但边界仍是分割头的一部分；
  - DermoSegDiff（`2308.02959`）用扩散模型显式建模边界；
  - USL-Net（`2309.13289`）用不确定性做无监督自学习，但目标是省标注，不是跨任务传递。
  - **你的差异点**：边界不确定图是**显式输出物**，既用于门控特征融合（第一部分内部），又作为**可靠性度量传递给第二部分的分类器**（跨部分接口）。前人的边界模块用完就丢，你的边界模块产出一个下游要用的量。
- 消融：baseline / +边界辅助损失（仅监督、不门控）/ +门控 / +逐尺度自适应权重 / U(x) 的不同定义方式（边界分支输出 vs MC-dropout vs 多尺度预测方差）。

**创新点 2：频域子带解耦与可学习高频选择（替换标准 bottleneck 或 ASPP）**

- **动机（这一段比息肉场景好写得多）**：皮肤镜图像里，病灶边界是高频，**但毛发、气泡、标尺刻度、皮肤纹理也是高频**。所以"增强高频"这个在息肉/CT 上常用的套路，在皮肤镜上会把伪影一起放大。真正需要的是**可学习地选择哪些高频该保留、哪些该抑制**——这个动机是皮肤镜特有的，不是从别的任务搬来的。
- 做法：Haar DWT 一级分解得到 LL / LH / HL / HH 四个子带。LL（整体形状、光照）走大感受野分支；三个高频子带**分别**做方向敏感的小卷积（LH 水平边界、HL 垂直、HH 对角），再用 SE/CBAM 式通道注意力（`1709.01507` / `1807.06521`）学习子带选择权重；IDWT 重建后与原特征融合。
- **加分实验（成本极低、说服力强）**：做 **DCT 频带截断消融**——把最高频段逐步砍掉看 DSC 怎么变；再用毛发遮挡的合成图跑一遍。这能定量回答"毛发伪影到底在哪个频段"，直接支撑动机论述，图也好看。
- 参考：Wavelet-based High-Frequency Enhancement（`2308.13442`）、SkinMamba 的 frequency boundary guidance（`2409.10890`）、Frequency-Spatial Saliency（`2010.04022`）、Wavelet+LBP U-Net（`1805.05239`）。
- **⚠️ SkinMamba（`2409.10890`）已经做了"频域+边界"的组合，你必须读它并在相关工作里明确区分**：它是"频率边界引导的状态空间模型（Mamba）"，你是"方向解耦子带 + 可学习高频选择 + 不确定度作为跨任务接口"，主干也不同。
- 消融：无频域 / 仅低频 / 仅高频 / 方向解耦 / +通道选择 / DWT 层数 / DCT vs DWT / 与直接加 CBAM 对比（证明频域分解比单纯注意力有效）。

**创新点 3：面向标注歧义的软边界复合损失**

- **动机**：`2508.09381`（What Can We Learn from Inter-Annotator Variability in Skin Lesion Segmentation）实测证明皮肤镜标注存在显著的**标注者间分歧**，病灶边界本身就没有唯一正确答案。硬二值 GT + Dice 会惩罚这种合理分歧，产生无意义的梯度冲突。
- 做法：`L = λ₁·L_Dice + λ₂·L_BCE(w) + λ₃·L_Boundary + λ₄·L_Tversky`
  - `w = 1 + α·exp(-d²/2σ²)`，`d` 为像素到 GT 边界的距离，使边界带获得更高权重；
  - `L_Boundary` 用 Boundary Loss（`1812.07032`）或 boundary-IoU 的可微近似；
  - `L_Tversky`（`1706.05721`）控制 FP/FN 的不对称惩罚——皮肤镜里**漏检（低 SE）比过检（低 SP）临床后果更严重**，据此调 α/β 是一个有临床依据的设计选择；
  - **软标签**：边界带内不用 0/1，而用距离变换生成的 [0,1] 连续值作为 target，把"标注歧义"显式编码进监督信号。
- 消融：Dice+BCE / +边界加权 / +Boundary 项 / +Tversky / +软标签 / Tversky 的 α β 敏感性 / λ 敏感性。
- **这个创新点的好处**：不依赖任何新结构，纯损失函数，实现半天，消融表能列 6–7 行，性价比极高。

### 3.3 对比实验（亲手复现 4 个，表格扩到 19 行）

**选模型的原则：每个创新点配一个直接对手 + 代码必须真能跑。** 下面 4 个都已用 GitHub API 和 README 实测核实过（2026-10-01）：**全部有官方仓库、全部有 `train.py`、全部在 ISIC2017/2018 上报告过结果**。年份 2015 / **2024** / **2024** / **2025**，**三个是 2024–2025 的工作**。

| # | 模型 | 年份 / 发表 | 仓库 | Stars | 卡住哪条路线 |
|---|---|---|---|---|---|
| 1 | **U-Net** | 2015 | `segmentation_models.pytorch` | — | 通用 CNN 锚点，也是本文骨干的起点。**不可省**——没有它，"我的改进相对于什么"就无从谈起 |
| 2 | **LB-UNet** | **MICCAI 2024** | `xuxuxuxuxuxjh/LB-UNet` | 45★ | **轻量 + 边界辅助**，创新点 1（边界门控）最新的正面对手。纯 PyTorch，无 CUDA 扩展 |
| 3 | **UltraLight-VM-UNet** | **Patterns（Cell 子刊）2024** | `wurenkai/UltraLight-VM-UNet` | **364★** | 超轻量 SOTA，**0.049M 参数 / 0.060 GFLOPs**，给出 Params/FLOPs 权衡的极端参照点。表里 star 最高、影响力最大的一个 |
| 4 | **SkinMamba** | **ACCVW 2025 Oral** | `zs1314/SkinMamba` | 54★ | **frequency boundary guidance**，和创新点 2（频域子带解耦）几乎正面对撞，是表里最有说服力的对手。提供权重下载 |

第 2–4 个都需要 `mamba_ssm` / `causal_conv1d`（LB-UNet 除外，它是纯 PyTorch）。**在 Linux 服务器上 `pip install mamba_ssm causal_conv1d` 即可**，不是障碍；只需注意它们的 wheel 要和你的 torch / CUDA 版本匹配，装之前先确认服务器上 `nvcc --version` 和 `python -c "import torch; print(torch.__version__, torch.version.cuda)"` 的输出。

**为什么不选 BA-Transformer / VFFM-UNet 进核心 4 个**：
- **BA-Transformer**（MICCAI 2021，`jcwang123/BA-Transformer`，133★）是边界路线的经典，但 LB-UNet 已经覆盖了同一条路线且更新。**它的 ISIC2018 数字直接引用原文即可**，不必自己跑。
- **VFFM-UNet**（2024-12，`11penguins/VFFM-UNet`，9★，纯 PyTorch，跑 ISIC2017/2018/PH2）代码可用但发表处未明、影响力低，作为**备选第 5 个**或消融对照更合适。

### 3.4 消融与额外实验

1. **模块消融总表**：baseline → +创新点1 → +创新点2 → +创新点3 → 全部。核心表格，必须有。

## 4. 第二部分详细设计：分割引导的病变分类

### 4.1 数据与协议

| 数据集 | 规模 | 有无官方 mask | 用途 |
|---|---|---|---|
| **ISIC 2017（Task1 + Task3）** | 2000 / 150 / 600，**3 类** | ✅ **有，且与分类图一一配对** | **方法上限验证 + 真 mask 消融** |
| **HAM10000 / ISIC 2018 Task3** | 10015 张，**7 类** | ❌ 无 | **主 benchmark**：大规模 + 极度不平衡 + 无标注 |

**⚠️ 一个已经用 ID 级实测确认的结构性事实：ISIC 2018 Task1 的分割标注和 Task3（HAM10000）的分类数据是两批完全不同的图像，交集为 0。**

实测方式是把双方全部 image ID 取交集：Task1 train（2594 张，`ISIC_0000000`→`ISIC_0016072`）、val（100 张）、test（1000 张）三个划分与 HAM10000（10015 张，`ISIC_0024306`→`ISIC_0034320`）的交集**均为 0**。虽然 ID 区间有交叠，但没有任何一个 ID 相同，说明是 ISIC Archive 里不同批次的图像。

> 官方 challenge 页面和 arXiv 1902.03368（challenge 综述）都**没有明文声明**两个 task 的图像不相交，只说"over 12,500 images across 3 tasks"。所以这个结论要靠 ID 级比对来支撑——**你可以把这个比对写进论文的数据说明里，它比引用一句模糊的官方表述更有说服力**，也顺手堵住"你的 mask 是从哪来的"这个必问问题。

**但这里有一个转机，而且它让第二部分的实验设计变得更强：ISIC 2017 的分割任务（Task1）和分类任务（Task3）用的是同一批图像。** 实测 `ISIC-2017_Training_Part1_GroundTruth.zip`（2000 个 mask ID）与 `ISIC-2017_Training_Part3_GroundTruth.csv`（2000 个 image_id）的 ID 集合**完全相同**。也就是说 ISIC 2017 天然提供了「图像 + 真 mask + 类别标签」的三元组。

于是第二部分采用**双数据集设计**，两个数据集各自回答一个不同的问题：

| | ISIC 2017 | HAM10000 / ISIC2018 Task3 |
|---|---|---|
| mask 来源 | **官方真 mask**（配对） | 第一部分模型**自动生成的伪 mask** |
| 类别 | 3 类（melanoma / seborrheic_keratosis / nevus） | **7 类**，含 DF(115)、VASC(142) 两个 1% 稀有类 |
| 规模 | 2000 / 150 / 600 | 10015 |
| 回答的问题 | **方法的上限是多少**——在有完美 mask 的理想条件下，双分支融合 + ABCD 先验能带来多少提升 | **方法在真实条件下是否可用**——没有 mask 标注、类别极度不平衡时，靠自动 mask + U(x) 门控还能不能work |
| 独有实验 | **真 mask vs 自动 mask** 的直接对照（这是全篇最有说服力的一张消融表） | 稀有类逐类 F1、MEL 召回率 |

**这个设计比原方案强在哪**：原来"真 mask vs 自动 mask"消融只能勉强找一个有标注的子集来做，现在它是一个**天然的跨数据集实验**，而且顺带回答了"你的方法依赖 mask 质量到什么程度"这个评委一定会问的问题。同时它也把 PLCRD 的差异化论述落到实处——PLCRD 是"训练用真 mask、推理不用"，你是"两个数据集分别验证真 mask 上限与伪 mask 实用性"。

**自动 mask 生成流程**（HAM10000 侧）：用第一部分训练好的分割模型对 10015 张图纯推理，约 10 分钟。三个必须在论文里交代的点：
1. 自动 mask 有对有错，所以**必须有机制识别并降低错误 mask 的影响**——这正是创新点 1 的 U(x) 门控存在的理由，逻辑闭环。
2. **D29–D30 就要抽查 50 张**人工看质量，别等到第 10 周才发现不能用。
3. 与 **PLCRD（`2607.18773`）** 的区别写进相关工作：它是特权信息蒸馏（推理时不用 mask），你是训练推理都用自动 mask + 不确定性显式门控，不做蒸馏。

**ISIC 2017 三类的实际分布**（写论文要用准确数字）：训练集 melanoma 374 / seborrheic_keratosis 254 / nevus 其余（1372）；验证集 150 张（melanoma 30 / SK 42）；测试集 600 张（melanoma 117 / SK 90 / nevus 393）。**同样不平衡**（melanoma 只占 18.7%），所以创新点 3 的不平衡处理在 ISIC2017 上也能验证，不是只在 HAM10000 上有效。

**HAM10000 划分**：官方 ISIC2018 Task3 提供 train（=HAM10000, 10015）/ val / test，test 标签曾长期不公开。多数论文用 10015 张自行做**分层划分**（如 70/10/20）。你必须明确写出划分方式和随机种子。**建议：主结果用自己固定的分层 70/10/20（保证可复现），另附一组官方 train/val 划分的结果以便和已发表工作对齐。**

> 📌 **一个容易写错的细节**：HAM10000 官方 CSV 的列名是 `image,MEL,NV,BCC,AKIEC,BKL,DF,VASC` —— 光化性角化那一列叫 **`AKIEC`**，不是 `AK`。论文表格里用 AK 没问题（社区习惯），但读 CSV 时别找错列。

### 4.2 三个创新点

**创新点 1：分割不确定性感知的双分支动态融合（核心创新点）**

- 做法：
  - **全图分支**：整张 224² 图像输入，保留皮肤纹理、色素网、光照与周边上下文；
  - **ROI 分支**：用自动 mask 抠出病灶，外接矩形扩展 10–20% 后 resize 到 224²，专注病灶内部结构；
  - **融合**：不是简单相加或拼接，而是由第一部分输出的 **U(x) 派生的全局 mask 置信度** `c = 1 − mean(U(x))`（或边界带面积占比）动态决定权重：`F = c·F_roi + (1−c)·F_full`。mask 可靠 → 偏重 ROI；mask 不可靠（低对比度、毛发遮挡、病灶占满全图）→ 偏重全图。
- **保底变体（务必同时实现，这是防负结果的保险）**：不裁剪 ROI，而是把 mask 作为**第四个输入通道**（soft guidance），或作为空间注意力图逐像素调制特征。这个变体几乎不可能比全图单分支差，因为它是单分支的严格超集。**如果抠图版 ROI 分支不涨点，就用软引导版作主方案，抠图版降级为消融项。** 论文照样成立。
- 与已有工作的区别（必须写清楚）：
  - MT-TransUNet（`2112.01767`）：共享 encoder + 多任务 token，**端到端联合训练**；
  - GS-TransUNet（`2502.16748`）、MDSkin-Net（`2609.30855`）：架构层面耦合的多任务框架；
  - Dermo-DOCTOR（`2102.01824`）：双编码器并发检测+识别；
  - Multi-scale Feature Enhancement（`2412.00351`）：医学多任务的通用特征增强；
  - PLCRD（`2607.18773`）：特权信息蒸馏，推理时不用 mask；
  - **你的差异**：**两阶段级联 + 不确定性显式门控**。分割先训好并冻结，分类阶段把 mask 及其可靠性一起作为输入。这个选择有三个可论证的优点：两部分可独立评估（符合毕业论文结构）、算力省一半（不需端到端联合训练）、临床可解释（分割结果可单独给医生核查）。
- 消融：全图单分支 / ROI 单分支 / 固定权重融合（c=0.5）/ 学习式门控 / **不确定性门控（你的）** / 真mask vs 自动mask / 抠图 vs 软引导。
- **这张消融表是第二部分的核心，而且几乎一定能做出正结果**——不确定性门控是固定融合的超集，最坏情况退化为固定融合。

**创新点 2：ABCD 规则的形态学先验显式注入**

- 做法：从 mask 计算四个可解释量，对应皮肤科教科书的 ABCD 规则：
  - **A（Asymmetry 不对称性）**：mask 沿长轴/短轴翻转后与原 mask 的 IoU，两轴分别算；
  - **B（Border 边界不规则度）**：周长²/面积（圆形度）、凸包缺陷数与深度、边界分形维数；
  - **C（Color 颜色）**：mask 内做 K-means 聚类得到的主色数量与各色占比（**注意必须用第一部分 mask 内的像素统计，这才是"分割引导"的落点**）；
  - **D（Differential structures 结构多样性）**：mask 内用简单纹理描述子（LBP / Gabor 响应）统计结构种类数。
- 注入方式：归一化后的形态学向量经一个小 MLP 编码，与视觉特征**拼接**，或用它**调制**最后一层 logits。两种都实现，作为消融。
- 参考：Segmentation and ABCD rule extraction（`2106.04372`）、Machine Vision ABCD Assessment（`2601.15539`）、MDSkin-Net 的 pattern analysis priors（`2609.30855`，它用了皮肤病学先验，你要说明自己的先验是**从 mask 显式计算出来的可解释量**，而非网络内部学的隐式先验）。
- **成本极低**：形态学量用 `skimage.measure` + `cv2` 就能算，10015 张全部算完约 2–3 分钟，纯 CPU；参数增量 < 0.1M。
- **额外产出（很有价值）**：一张"可解释性表"，把每个样本的 A/B/C/D 分数与最终诊断并列展示，再配 Grad-CAM（`1610.02391`）热力图。医生看得懂的东西，答辩评委也看得懂——这是纯黑箱分类器给不了的。可解释性方法本身也有坑，`2412.03166`（Are Explanations Helpful?）系统比较了各种 XAI 方法在皮肤镜分类器上的表现，做可视化前先读它。
- 消融：无 ABCD / +A / +A+B / +A+B+C / +全部 / 拼接 vs 调制 / 用真 mask 算 vs 用自动 mask 算。

**创新点 3：稀有类导向的不平衡处理 + 边界带对比正则**

- 做法：
  - (a) 用 **Class-Balanced Loss**（`1901.05555`）或 **LDAM**（`1906.07413`）替换普通交叉熵；
  - (b) 类别平衡采样（对 DF/VASC 过采样，对 NV 欠采样）；
  - (c) **边界带对比正则（这是与前人不同的地方）**：用第一部分的 U(x) 定义"病灶边缘带"像素，在边缘带特征上施加监督对比损失，拉近同类、推开异类。**理由**：MEL 与 NV 的鉴别线索恰恰在边界（色素网是否规则、边界是否模糊、有无放射状条纹），而不在病灶中心。把对比学习的采样重心放在边界带是有临床依据的，不是随便挑的区域。
- 参考：**Handling Class Imbalance in Skin Lesion Classification（`2512.15837`，2025-12 的系统对比，必读——它能直接告诉你哪些平衡技术有效哪些无效，省掉大量试错）**、SuperCon（`2202.05685`）、ProCo（`2209.00183`）、FoPro-KD（`2305.17421`，长尾医学识别的傅里叶提示蒸馏）、PatchAttn + Diagnosis-Guided Loss Weighting（`1905.02793`）。
- 消融：CE / +CB Loss / +平衡采样 / +LDAM / +边界带对比 / 各稀有类 F1 逐项变化 / **对比区域选边缘带 vs 中心 vs 全图的对照**。
- 最后那个对照很重要：它直接验证"边界带是鉴别性区域"这个假设。如果边缘带不如全图，就诚实报告并改为全图对比——这个对照本身就是有价值的实验结论，不会白做。

## 5. 算力与周期预算（单卡 16GB）

| 项目 | 估算 |
|---|---|
| 显存峰值 | 分割：核心 4 个模型都是轻量级（UltraLight-VM-UNet 仅 0.049M 参数），@256² batch16 约 3–6GB；你自己的方法若用 Transformer 主干约 7–9GB。分类：双分支 @224² batch64 约 8–10GB。**16GB 全程有余量**，服务器上若显存更大可直接加大 batch 提速 |
| 单次训练时长 | 分割轻量级（U-Net / LB-UNet / UltraLight-VM-UNet）200ep ≈ **0.5–1.2h**；SkinMamba 200ep ≈ **1.5–2.5h**（Mamba 扫描有额外开销）；分割重量级（TransUNet / SegFormer，只在消融里用）200ep ≈ **2.5–3.5h**；分类单分支 50ep ≈ **30min–1h**；分类双分支 50ep ≈ **1–1.5h** |
| 第一部分总量 | 4 个亲手复现对比（≈5 GPU·h）+ ~18 组消融（≈20 GPU·h）+ 下游效用评估（≈3 GPU·h）≈ **28 GPU·h** |
| 第二部分总量 | 4 个对比含 1 个自实现端到端变体（≈5 GPU·h）+ ~18 组消融（≈16 GPU·h）+ 形态学量计算（纯 CPU，忽略）≈ **21 GPU·h** |
| **合计** | **~49 GPU·h ≈ 单卡连续跑 2 天** |

对比原息肉方案的 120–130 GPU·h，**省掉约 60%**；对比"每部分复现 10+ 个模型"的做法，也省掉了近 30 GPU·h。更重要的是单次实验从 2.5–3h 降到 0.5–1.5h，**试错成本降了 2–3 倍**——这才是"见效快"的真正来源。

> 省下来的算力建议投到**消融表的厚度**上，而不是对比表的宽度上。盲审看的是"你的每个设计选择有没有证据"，消融表比对比表更能回答这个问题。

**排期（4 个月，含写作）**

| 周期 | 内容 |
|---|---|
| 第 1–2 周 | 环境搭建、数据下载与目录组织、复现 U-Net 与 TransUNet、**写统一评测脚本** |
| 第 3–6 周 | 第一部分三个创新点 + 消融 + 对比表 + 下游效用评估 |

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| **HAM10000 无 mask**（已 ID 级实测确认） | ISIC2018 Task1 与 HAM10000 的 image ID **交集为 0**，不能用 Task1 的 mask。对策是**双数据集设计**（§4.1）：HAM10000 用第一部分模型自动生成伪 mask 验证实用性，**ISIC2017 用官方真 mask 验证上限**（ISIC2017 的 Task1 与 Task3 是同一批 2000 张图，已实测 ID 集合完全相同）。这个设计把原本的缺陷变成了两部分递进关系的定量证据 |
| **分类总精度饱和，涨不动** | 主指标改为 Balanced Accuracy / Macro-F1 / 逐类 F1；主战场放在 DF、VASC 两个 1% 占比的稀有类（有 3–8 点空间）；framing 写成"改善稀有类识别与可解释性"而非"提高精度" |
| **自动 mask 质量差，导致 ROI 分支负结果** | **提前实现软引导变体**（mask 作为第四通道 / 空间注意力），它是全图单分支的严格超集，几乎不可能负结果；抠图版降级为消融项。另外 D29–D30 就要抽查 50 张自动 mask，别等到第 10 周才发现。表 4-1b 的"随机 mask 对照组"能帮你判断到底是 mask 没信息还是模型没用上 |
| **对比模型只有 4 个，盲审嫌单薄** | 用 §3.3 / §4.3 的"引用原文扩表"策略把每张表撑到 **19 行**，自己只亲手跑 4 个对比 + 3–4 个消融配置；省下的算力投到消融表厚度上。**答辩话术**：对比模型的选择原则是"每个创新点配一个直接对手 + 一个经典锚点"，而非数量堆砌；两张表年份覆盖 2015–2026，2023 及以后的行分别有 4 行和 7 行 |
| **专用对比模型拿不到代码**（已逐个实测） | **确认无官方代码**：MDSkin-Net(`2609.30855`)、PLCRD(`2607.18773`)、LSSF-Net(`2409.01572`) —— 仓库名搜索与代码搜索均零结果，arXiv 摘要无 code availability 声明。**有代码但需验证**：MT-TransUNet（`JingyeChen/MT-TransUNet`，22★，README 仅三行容易搜漏，实际有 69 个文件含 `train.py`）、GS-TransUNet（3★）。对策：这两个**先各花半天验证可跑通**；跑不通就自己实现端到端多任务简化版（~150 行、1 天），标注"本文实现的变体"。无代码的三篇只在相关工作里差异化论述 + 引用原文数字加脚注。**分割侧不存在这个问题**：LB-UNet / UltraLight-VM-UNet / SkinMamba 都已核实有 `train.py` 且跑 ISIC2017/2018 |
| **Mamba 系 baseline（SkinMamba / UltraLight-VM-UNet）在 DSC 上打平或超过你** | 真实风险，提前布三条退路：① 主战场不只看 DSC，同时看 SE/SP/HD95 和小病灶分桶；② **不要把自己定位成轻量方法**（UltraLight-VM-UNet 只有 0.049M 参数，拼参数量必输），卖点放在边界质量与跨任务效用；③ **下游效用评估表（§3.4 第 3 项）是你独有的武器**——即使 DSC 打平，"哪个分割模型的 mask 最有利于下游分类"只有你在回答。详见 §3.3 的警示框 |
| **端到端多任务比你的级联更强** | 提前准备回应：级联的优势是两部分可独立评估、算力省一半、分割结果可单独供医生核查；并**诚实报告自实现的端到端变体结果**，如果它更强就如实写并讨论适用场景。评委欣赏诚实的对比，反感藏拙 |

### 备选 B：息肉分割「精度 → 泛化」（原主推）

- 第一部分：边界感知 + 频域多尺度聚合的息肉分割网络（Kvasir-SEG + CVC-ClinicDB，PraNet 官方 1450/162 划分，352²）。创新点：边界不确定性门控跳跃连接、频域-空域双域多尺度聚合（替换 RFB）、边界与难样本联合加权损失。
- 第二部分：域偏移鲁棒化。创新点：内容-风格解耦的课程式频域风格增强（只换幅度谱、保留相位谱）、边界不确定性引导的选择性伪标签自训练、参数冻结的轻量测试时自适应。
- 接口同样是边界不确定图 U(x)，递进关系同样成立。
- **优点**：泛化部分提升空间大（跨库掉点普遍 5–15 个点），故事好讲，12+ 个 baseline 现成，社区评测协议统一（对比表可直接引用已发表数字）。
- **缺点**：~120–130 GPU·h（是方案 A 的 **2.5 倍**）；单次实验 2.5–3h；**第二部分的域泛化/TTA 对随机种子敏感，有做出负结果的真实风险**；arXiv 上 21 个月 74 篇，同质化最严重。
- 论文在 `paper/04_alt_polyp_accuracy/`（11 篇）与 `paper/05_alt_polyp_generalization/`（13 篇）。

### 备选 C：息肉分割「精度 → 轻量化实时」

- 第一部分同备选 B；第二部分改为知识蒸馏 + 结构重参数化 + 通道剪枝，面向床旁/移动内镜设备，主打 Params/FLOPs/FPS 硬指标。
- **优点**：效率类指标客观、不需要争 SOTA、模型小训练快；"设计高精度网络 → 压缩到可部署"是硕士论文最经典、最不会被质疑工作量的结构。
- **缺点**：两部分偏并列而非递进；MicroAUNet（`2511.01143`）已做边界+蒸馏，LightMIS（`2609.28327`）、DepthPolyp（`2605.16519`）也在做轻量化，需要找差异点。
- 论文在 `paper/06_alt_efficiency/`（5 篇）。

### 11.3 指标实现

- **分割**：
  - `DSC / IoU / SE / SP`：自己写二十行即可。注意前景为空的处理方式要全表统一。
  - `HD95 / ASSD`：`medpy.metric.binary.hd95` / `assd`，或 `surface-distance` 包（Google 出的，带 spacing 参数，更严谨）。皮肤镜图像通常按各向同性像素处理，spacing 传 `(1,1)`。
  - `boundary-IoU`：参考 "What Do We Learn by Evaluating Image Segmentations?" 的实现（GitHub `isbellab` 组织下）。
- **分类**：
  - `sklearn.metrics` 的 `balanced_accuracy_score`、`f1_score(average=None)`（拿逐类 F1）、`roc_auc_score(multi_class='ovr')`、`classification_report`（一次拿全）。
  - **逐类 F1 必须用 `average=None`**，用 `average='macro'` 会把 DF/VASC 的信息平均掉，正是你要突出的东西。
  - 混淆矩阵用 `ConfusionMatrixDisplay` 画，7×7 的图能直观展示 MEL↔NV、BKL↔NV 这两对主要混淆。
- **形态学量（ABCD）**：`skimage.measure.regionprops`（面积、周长、离心率、主轴）、`cv2.convexHull` + `cv2.convexityDefects`（边界不规则度）、`skimage.feature.local_binary_pattern`（结构多样性）、`sklearn.cluster.KMeans` 在 Lab 色彩空间上做（颜色数）。
- `Params / FLOPs`：`thop` 或 `fvcore`；`FPS` 要注明测试硬件和 batch=1。
